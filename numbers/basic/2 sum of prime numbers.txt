Middle of Three
Difficulty: BasicAccuracy: 54.8%Submissions: 93K+Points: 1
Given three distinct numbers a, b and c. Find the number with a value in the middle (Try to do it with minimum comparisons).

Examples :

Input: a = 978, b = 518, c = 300
Output: 518
Explanation: Since 518>300 and 518<978, so 518 is the middle element.
Input: a = 162, b = 934, c = 200
Output: 200
Exaplanation: Since 200>162 && 200<934, So, 200 is the middle element.
Input: a = 246, b = 214, c = 450
Output: 246


Constraints:
1<=a, b, c<=109
a, b, c are distinct.

Minimum value of n = 1

Maximum value of n = 50,000

tc ans sc o(1)

import java.util.Scanner;

public class PrimeDigitSum {

    static int primeSum(int n) {
        int sum = 0;

        while (n > 0) {
            int digit = n % 10;

            if (digit == 2 || digit == 3 || digit == 5 || digit == 7) {
                sum += digit;
            }

            n = n / 10;
        }

        return sum;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        int result = primeSum(n);

        System.out.println(result);
    }
}
